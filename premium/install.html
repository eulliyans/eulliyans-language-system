EULLIYAN'S Premium Language System

Developer Installation Guide — Version 1.0.0

1. Required Files

Copy the required files into your website project:

your-website/
│
├── index.html
├── eulliyans-language.js
│
├── languages/
│   ├── en.js
│   ├── bn.js
│   ├── ar.js
│   ├── hi.js
│   ├── ur.js
│   ├── fr.js
│   └── es.js
│
└── premium/
    ├── language-premium.js
    └── config.example.js

The six standard languages are included in the Core System. Spanish is shown as an example of an additional Premium language.

2. Add Language Selector

<select id="languageSelector">
  <option value="en">English</option>
  <option value="bn">বাংলা</option>
  <option value="ar">العربية</option>
  <option value="hi">हिन्दी</option>
  <option value="ur">اردو</option>
  <option value="fr">Français</option>
</select>

3. Add Translatable Content

<h1 data-i18n="common.welcome">
  Welcome
</h1>

4. Load the Core Engine

Load the Core Engine first, followed by the required language dictionaries. 

<script src="eulliyans-language.js"></script>

<script src="languages/en.js"></script>
<script src="languages/bn.js"></script>
<script src="languages/ar.js"></script>
<script src="languages/hi.js"></script>
<script src="languages/ur.js"></script>
<script src="languages/fr.js"></script>

<script>
  EULLIYANS_LANG.init({
    defaultLanguage: "en",
    fallbackLanguage: "en"
  });
</script>

5. Load the Premium Module

Load the Premium Module after initializing the Core Engine. 

<script src="premium/language-premium.js"></script>
<script src="premium/config.example.js"></script>

6. Add More Languages

Create an additional dictionary file and configure it in config.example.js.

Example Spanish configuration:

{
  code: "es",
  name: "Spanish",
  nativeName: "Español",
  file: "languages/es.js",
  direction: "ltr"
}

7. RTL and LTR Support

LTR languages:

  • English
  • Bengali
  • Hindi
  • French
  • Spanish

RTL languages:

  • Arabic
  • Urdu

Set the appropriate direction in the language configuration: 

direction: "ltr"

or:

direction: "rtl"

8. Important Notes

• Load the Core Engine before its language dictionaries.

• Initialize the Core Engine before loading the Premium configuration.

• Add the required dictionary files to the correct folders.

• Use the same language code in the dictionary and configuration.

• Update file paths according to your website structure.
