EULLIYAN'S Premium Language System

Developer Installation Guide — Version 1.0.0

1. Required Files

Copy these files into your website project:

your-website/
│
├── index.html
├── eulliyans-language.js
│
├── languages/
│   ├── en.js
│   └── fr.js
│
└── premium/
    ├── language-premium.js
    └── config.example.js

2. Add Language Selector

<select id="languageSelector">
  <option value="en">English</option>
</select>

3. Add Translatable Content

<h1 data-i18n="common.welcome">
  Welcome
</h1>

4. Load the Core Engine

<script src="eulliyans-language.js"></script>
<script src="languages/en.js"></script>

<script>
  EULLIYANS_LANG.init({
    defaultLanguage: "en",
    fallbackLanguage: "en"
  });
</script>

5. Load the Premium Module

<script src="premium/language-premium.js"></script>
<script src="premium/config.example.js"></script>

6. Add More Languages

Add a dictionary file and register its language in config.example.js. 

{
  code: "fr",
  name: "French",
  nativeName: "Français",
  file: "languages/fr.js",
  direction: "ltr"
}

7. Important Notes

• Load the Core Engine and default dictionary first.

• Load the Premium Module after Core Engine initialization.

• Update file paths according to your website structure.
